# Claude Code Adapter

This adapter turns the portable skills into personal Claude Code skills.

- Destination: `~/.claude/skills/<skill-name>/SKILL.md`
- Global contract: user-level `~/.claude/CLAUDE.md` import
- Model mapping: `models.yaml`
- Invocation policy: `skill-policy.yaml`

Claude Code supports personal skills in `~/.claude/skills/`, which are available across projects.
